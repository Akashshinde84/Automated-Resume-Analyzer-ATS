# Sample resumes

Resume files are ignored by Git to prevent accidental exposure of personal
information. Do not place real candidate data in the repository.

Phase 9 adds [20 CC0 synthetic profile sources and gold labels](../docs/evaluation/resumes.json).
`backend/scripts/evaluate_nlp.py` generates 10 PDF and 10 DOCX documents temporarily,
evaluates them, and cleans them up. See [annotation scope](../docs/evaluation/annotation-review.md)
and [measured results](../docs/evaluation/nlp_results.md). No real resumes were collected.
